# Changelog

What's new in each version of Cecily Tasks, starting with the first whose source is published.

## 1.1 — 2026-11-01

- Cecily Tasks is open source, under the MIT licence.
- Quick entry takes the area the lists are narrowed to, unless you choose another, and None in a column now wins over what the first line names.
- Quick entry opens instantly, ready to type, and leaves the app you were using in front: it doesn't bring Cecily Tasks forward.
- Attaching a file no longer leaves a temporary copy of it behind.
