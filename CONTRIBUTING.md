# Contributing

Thanks for your interest.

## Issues

Bug reports and ideas are welcome as [issues](../../issues). For a bug, say what you did, what you expected and what happened, with the app's version (in its About window) and your macOS or iOS version. Please leave out anything personal from your own data.

## Pull requests

Pull requests aren't accepted for now, and any that arrive are closed. If you've found a fix, describe it in an issue instead.

## Building and testing

The README says how to build the code with your own Apple developer team and run its tests.
